Backend-разработчик (Python) — WattsTap
=========================================

О компании и проекте
--------------------

WattsTap — мобильная tap-to-earn игра с элементами RPG.
Игра запускается как Telegram Mini App, в планах — выход на WeChat.
Клиент написан на Unity (WebGL). Бэкенд разрабатывается с нуля.

Ищем опытного Python-разработчика, который возьмёт на себя
проектирование и реализацию серверной части проекта.


Чем предстоит заниматься
-------------------------

    - Проектирование и разработка REST API с нуля
    - Реализация игровой логики на стороне сервера:
        - система тапов с серверной валидацией (anti-cheat)
        - прогрессия игрока (ресурсы, уровни, XP)
        - система апгрейдов и инвентаря
        - оффлайн-бонусы, ежедневные награды
        - магазин, турниры, лидерборды
    - Интеграция с Telegram Bot API и Mini Apps
    - Реализация платежей через BTN (Telegram Stars / TON)
    - Реферальная система и социальные функции
    - Настройка инфраструктуры (Docker, CI/CD, деплой)
    - Написание тестов, документации API


Обязательные требования
-----------------------

    Опыт и язык:
        - Python 3.10+, от 3 лет коммерческого опыта
        - FastAPI или аналогичный async-фреймворк (aiohttp, Starlette)

    API:
        - Проектирование и реализация REST API
        - JWT-аутентификация
        - Валидация данных

    Telegram:
        - Опыт работы с Telegram Bot API
        - Валидация initData (HMAC-SHA256)
        - Понимание Telegram Mini Apps

    Общее:
        - Понимание принципов server-authoritative архитектуры
        - Опыт работы с высоконагруженными системами
        - Умение писать чистый, поддерживаемый код


Будет плюсом
------------

    - Опыт с Telegram Bot Payments / Telegram Stars / BTN
    - Опыт интеграции с TON blockchain
    - Знакомство с WeChat Mini Programs и WeChat Pay
    - Опыт разработки бэкенда для игр (game server)
    - Опыт с anti-cheat системами
    - Опыт работы с Unity-клиентами


Стек проекта
------------

    Язык:           Python 3.10+
    Авторизация:    JWT (Telegram initData)
    Платежи:        (BTN)
    Платформы:      Telegram Mini App, WeChat (планируется)


О проекте подробнее
-------------------

    Игровые механики (серверная валидация):
        - Тапы с энергией, критами, кулдаунами
        - 12 типов апгрейдов с многоуровневой прогрессией
        - Инвентарь: предметы, экипировка, мерж, прокачка
        - Магазин: сундуки (лутбоксы) и бустеры
        - Турниры с таблицами лидеров и наградами
        - Оффлайн-бонус (до 4 часов)
        - Ежедневные бонусы со стриком

    Социальные функции:
        - Реферальная система с бонусами
        - Список друзей с отслеживанием заработка
        - Лидерборды (глобальный, друзья, турнирный)

    Платежи:
        - Telegram: BTN / Telegram Stars
        - WeChat Pay (планируется)

    API: ~25 эндпоинтов, клиент уже реализован
