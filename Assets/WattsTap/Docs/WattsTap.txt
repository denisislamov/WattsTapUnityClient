Core loop
1. Основная механика игры это тапая зарабатывать монеты и опыт для улучшения уровня
2. Монеты нужны для апгрейда и покупки вещей, а также для апгрейда улучшений которые усиливают основные параметры игрока
   1. За каждый тап дается больше монет
   2. Оффлайн бонус увеличивается
   3. Количество ударов увеличивается и их восстановление уменьшается
3. Вещи можно улучшать поднимая им уровень и с помощью мержа одинаковых вещей которые дают больше бонусов
4. Получая опыт за тапы игрок увеличивает уровень который открывает новых персонажей и дает награды каждый новый уровень
5. Также чем больше игрок тапает тем больше вероятность занять призовые места в турнирах где награды в виде монет, бустеров и вещей
6. Чем больше игрок приглашает друзей тем больше он получит наград от их заработка при тапах


  

Mining
The main start screen where the player presses on character and gets coins.  This screen includes the following elements:
1. Panel with nickname, avatar and player level. The profit of coins that the player collecting per hour is also displayed (without pressing)
2. Daily bonus button, when the player press opens the pop-up daily bonus
3. The Tournament button, when a player press, opens a pop-up with a leaderboard of players
4. Player balance in watts coins
5. Dwarf with a hammer, when the player press on it, an animation of the hammer hitting the anvil occurs and the player receives coins in balance
6. Stamina scale. It can be made in the form of a thermometer where the temperature increases when the player quickly presses on the character in a row. The player needs to take a break so that the temperature scale drops and the player can start pressing again
7. Number of hammer blows. Hammer hits regenerate every X minutes. The player can also improve strikes, increase their number and recovery speed
8. Shop button - when press, it opens a shop where the player can buy boosters, items and other equipment for improvements
9. Bottom panel for switching screens which includes:
   1. Mining
   2. Inventory
   3. Upgrades
   4. Friends
   5. Quests
   6. Station


  
 
Level Up

Inventory

Daily Bonus
Ежедневный дейли бонус который игрок получает каждый день при первом заходе в игру. Если игрок пропускает день прогресс сбрасывается и игрок начинает заново получать цепочки наград. Игрок может вызвать дейли бонус с главного экрана майнинга кликнув на иконку дейли бонуса. Поп ап дейли бонуса включает в себя следующие элементы:
1. Заголовок Daily Bonus
2. Кнопка крестик закрывает данный поп ап
3. Иконка часов и текст Next reward in: 23:59. Когда игрок еще не забрал награду вместо таймера текста Ready
4. Шкала для долгосрочных наград на месяц, каждый месяц она обновляется 
5. Награды на 7 дней иконка имеет 3 состояния
   1. Когда игрок забрал  награду
   2. Когда награда доступна для сбора
   3. Когда награда будет доступна на следующий день или позже
6. Кнопка Collect при тапе забирает награду, кнопка имеет 2 состояния
   1. Готова к сбору
   2. Когда нет награды - кнопка серая неактивная


  





















Tournament
Временный турнир где игрок принимает автоматически участие. Игрок продвигается в турнире за получаемые монеты ТОЛЬКО при тапах. Это будет мотивировать игроков больше проводить время в игре и больше уравнивает шансы новых игроков с уже прокачанными. Вкладка турнир имеет 2 вкладки с лидербордом игроков и топ наградами в турнир. Рассмотрим каждую вкладку по отдельности. Длительность турнира месяц (данный параметр должен гибко настраиваться и меняться).
Leaderboard
Данная вкладка состоит из следующих элементов:
1. Заголовок Tournament + Кнопка Инфо при тапе на нее появляется бабл с текстом где есть основные правила турнира и как трекаются монеты в турнир ( с механики тапов)
2. Кнопка крести при тапе закрывает данный поп ап с турниром
3. Таймер окончания турнира
4. Вкладки для переключения между лидербордом игроков и топ местами с наградами
5. Топ лист игроков который состоит из:
   1. Место в турнире
   2. Аватарка игрока
   3. Имя игрока
   4. Уровень игрока
   5. Количество монет которое он заработал со старта турнира тапая по персонажу
  











Когда турнир недоступен и игрок тапает по иконке открывается данный поп ап
  

Когда турнир начался и игрок входит в игру ему вылетает автоматически поп ап и игроку нужно нажать кнопку Start для участия в турнире. Когда игрок нажимает Start ему открывается лидерборд игроков


  

Когда игрок занял призовое место при окончании турнира отображается поп ап с поздравлениями и наградами игрока
  

Когда игрок не занял призовое место при окончании турнира появляется поп ап с окончанием турнира

Shop
В магазин можно перейти  через вкладку майнинга нажав на кнопку Shop. Магазин состоит из 2х вкладок Chests and Boosters. Магазин служит также инвентарем для накопление сундуков и бустеров чтобы их активировать в нужный для игрока момент.
Chests
Рассмотрим вкладку Chests которая включает в себя следующие элементы:
1. Заголовок Shop
2. Кнопка закрытия магазина
3. Вкладки для переключения Chests and Boosters
4. Блоки с сундуками по редкости которые включают в себя следующие элементы
   1. Заголовок редкости сундука
   2. Описание сколько элементов включает сундук
   3. Иконка самого сундука
   4. Кнопка инфо которая показывает вероятности вещей в сундуке открывая поп ап с более детальной информацией
   5. Цена открытия сундука или кнопка Open с количеством доступных сундуков у игрока. 






  

















Open Chests
Открытие сундуков происходит по следующему флоу:
1. Появляется отдельные экран и игроку показывает палец чтобы нажать на сундук
2. Игрок тапает несколько раз по сундуки и вылетает по одной вещи при каждом тапе
3. Когда игрок проклацал все разы появляется все вещи как награда
4. Игрок нажимает тап чтобы выйти с данного экрана и вещи автоматически попадают в инвентарь игрока

3. Дают игроку моментальный  профит за 120 минут исходя из параметра профит за час
4. Дают игроку моментальный  профит за 300 минут исходя из параметра профит за час

Техническое задание для Telegram Web App: Wattstap MVP
1. Общее описание
На этапе MVP Wattstap - это двухмерная аркадная игра с элементами геймификации энергетики. Игроки взаимодействуют с игровым миром, накапливая энергию и виртуальную валюту. 
2. Функциональные требования
* Игровой процесс:
   * 2D аркада с простой механикой (например, удары молотом по наковальне).
   * Накопление очков жизни и игровой валюты (Watts).
   * Обмен Watts на криптовалюту KiloWatt.
   * Система уровней и достижений.
   * Возможность улучшения персонажа и инструментов.
   * Система стимулов для постоянного игрового процесса.
* Взаимодействие с Telegram:        
   * Авторизация через Telegram.
   * Отправка уведомлений о новых событиях в игре.
   * Возможность приглашать друзей.
* Интеграция с криптовалютой:
   * Обмен игровой валюты на реальную криптовалюту.
   * Поддержка различных криптовалютных кошельков.
   * Возможность стейкинга KiloWatt.
* Социальные функции:
   * Рейтинги игроков.
   * Глобальные и личные достижения.
   * Чат для общения игроков.
3. Нефункциональные требования
* Производительность: Игра должна работать плавно на различных устройствах.

Telegram Web App Wattstap: Архитектура
Введение
Предложенная архитектура для игры Wattstap представляет собой многоуровневую систему, объединяющую в себе современные технологии для создания динамичной и масштабируемой онлайн-игры.
1. Фронтенд игры
* React: Является основой для создания пользовательского интерфейса игры. Его компонентный подход позволяет эффективно структурировать код и упрощает разработку сложных пользовательских интерфейсов.
* Three.js: Используется для создания 3D-графики и анимаций. Он предоставляет мощный инструментарий для работы с трехмерными объектами, текстурами и освещением.
* PixiJS: Применяется для 2D-графики и может использоваться параллельно с Three.js для оптимизации производительности в некоторых случаях.
Структура:
* Компоненты: Разбивка пользовательского интерфейса на отдельные компоненты (кнопки, меню, игровое поле и т.д.).
* Контейнеры: Компоненты высшего уровня, которые связывают компоненты с состоянием приложения.
* Redux или Context API: Управление состоянием приложения.
2. Фронтенд для админки
* React: Обеспечивает гибкость и производительность при создании административной панели.
* AdminLTE: Предоставляет готовые компоненты и шаблоны для создания профессионально выглядящих административных панелей.
Структура:
* Дашборд: Обзорная панель с ключевыми метриками и графиками.
* Модули: Отдельные модули для управления различными аспектами игры (пользователи, предметы, контент и т.д.).
* Формы: Для создания, редактирования и удаления данных.
* Таблицы: Для отображения списков данных (пользователи, предметы, события).
3. Бэкенд
* Node.js: Предоставляет легкую и эффективную платформу для создания серверных приложений.
* Express.js: Фреймворк для Node.js, упрощающий разработку веб-серверов и API.
* GraphQL: Обеспечивает гибкий и эффективный способ взаимодействия между клиентом и сервером.
* PostgreSQL: Реляционная база данных для хранения игровых данных (пользователи, предметы, прогресс и т.д.).
Структура:
* API: GraphQL API для предоставления данных и выполнения операций над ними.
* Сервисы: Модули для выполнения бизнес-логики (аутентификация, авторизация, обработка платежей).
* База данных: PostgreSQL для хранения данных.
* Кэширование: Redis или Memcached для ускорения доступа к часто используемым данным.
4. Взаимодействие между компонентами
* Фронтенд и бэкенд: Взаимодействие через GraphQL API. Фронтенд отправляет запросы на сервер, а сервер возвращает необходимые данные.
* Фронтенд и база данных: Прямого взаимодействия нет. Все запросы к базе данных проходят через бэкенд.
  

  

5. Преимущества предложенной архитектуры
* Модульность: Разделение на отдельные компоненты упрощает разработку, тестирование и масштабирование.
* Гибкость: Использование современных технологий позволяет легко адаптировать систему под меняющиеся требования.
* Производительность: Оптимизация за счет использования кэширования и эффективных алгоритмов.
* Масштабируемость: Возможность горизонтального масштабирования для обработки большого количества пользователей.
* Безопасность: Использование надежных технологий и протоколов для защиты данных пользователей.
